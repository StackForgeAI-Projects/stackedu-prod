## Before you start

1. Open the app on a phone, tablet, or computer. The layout stacks on a small screen.
2. Use sample details where a form asks for them. Do not use real personal data unless you mean to.
3. Dates on the screens are shown as **DD-MM-YYYY**.
4. Create, update, and delete always ask you to confirm before they save.
5. If a step is not in a guide, do not assume it works.
